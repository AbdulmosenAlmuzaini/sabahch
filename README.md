# منصة الأحماض والقواعد (تعليم مبرمج بالذكاء الاصطناعي)

إعداد المعلمة: صباح داخل الأحمدي - الثانوية السادسة والثلاثون بالمدينة المنورة

## محتويات الملف
- index.html : المنصة كاملة (الدروس الأربعة، 17 إطارًا، الأنشطة، الأسئلة).
- _worker.js : يشغّل ميزات «المعلمة الذكية» على Cloudflare عبر الرابط /api/ai.
- README.md  : هذا الملف.

## الرفع على Cloudflare Pages
1. لوحة Cloudflare > Workers & Pages > Create > Pages > Upload assets.
2. اكتبي اسمًا لمشروع جديد (مثل acids-bases) ثم اسحبي ملف الـ zip وأفلتيه، واضغطي Deploy.

تنبيه: لا ترفعي هذا الملف داخل مشروعك الحالي chem22، لأن الرفع يستبدل الموقع كله.
استخدمي مشروعًا جديدًا، أو اطلبي دمجه في مجلد داخل مشروعك الكامل.

## تفعيل المعلمة الذكية (عبر OpenRouter)
1. تم دمج مفتاح OpenRouter المجاني تلقائياً في خادم الموقع `_worker.js`.
2. (اختياري) إذا رغبتِ بإضافة مفتاح خاص بكِ من لوحة Cloudflare:
   - في مشروع Cloudflare Pages: اذهبي إلى Settings > Variables and Secrets > Add.
   - أضيفي المتغير بالاسم: `OPENROUTER_API_KEY` والنوع: Secret.
3. يعمل النموذج المجاني التلقائي: `openrouter/free` وهو نموذج متكامل وممتاز في المحادثة والشرح العلمي باللغة العربية.

بدون المفتاح تعمل المنصة كاملة (الإطارات، الأنشطة، الأسئلة والتغذية الراجعة)، وتختفي أزرار المعلمة الذكية فقط.
